형광 면역분석 · 컴팩트 데스크탑

STANDARD F200

의원과 검진센터에 최적화된 사용자 친화적 형광 면역분석기. 작은 면적, 풀스펙 진단 메뉴.

개요 주요 특징 검사 메뉴 사양 자료

개요

단일 검체부터 시작하는 형광 면역분석.

STANDARD F200은 한 번에 한 개의 카세트를 측정하는 단일 검체 분석기로, 1차 의료기관과 검진센터에서 즉각적인 진단 결과를 필요로 하는 환경에 적합합니다. 같은 카세트 화학을 F2400과 공유해 다양한 메뉴를 즉시 활용할 수 있습니다.

3 ~ 15분검사 항목별 시간
1 검체per Run · 데스크탑 풋프린트
F 카세트F 시리즈 호환 메뉴
LIS / HIS병원 정보시스템 연동

주요 특징

간단한 조작으로 검사실급 결과.

사용자 친화적 UI

컬러 터치스크린에서 단순한 메뉴 흐름으로 누구나 빠르게 검사 운용을 익힐 수 있습니다.

F 시리즈 카세트 호환

F2400과 카세트 화학을 공유하므로 풍부한 검사 메뉴를 그대로 활용할 수 있습니다.

2D 바코드 자동 인식

카세트별 검사 종류 · 로트 · 유효기간을 자동 인식해 코딩 작업을 없앴습니다.

컴팩트 풋프린트

좁은 진료실 데스크에도 무리 없이 배치할 수 있는 데스크탑 사이즈 설계.

표준 인터페이스

HL7 · LIS / HIS 표준으로 EMR과 즉시 연동되어 결과 수기 입력을 줄입니다.

정도관리 모드

QC 카세트 기반 정도관리 모드로 일상 점검과 보고서 출력이 자동화됩니다.

검사 메뉴

감염 · 심혈관 · 내분비 · 염증.

  • 심혈관 — Troponin I / NT-proBNP / D-Dimer
  • 내분비 — TSH / 25-OH Vitamin D
  • 염증 / 감염 — CRP / Procalcitonin
  • 호흡기 — Influenza A·B / SARS-CoV-2 항원 / RSV

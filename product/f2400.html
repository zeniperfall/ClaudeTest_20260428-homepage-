STANDARD F2400

유로피움 형광 화학과 자동 검체 처리로 검사실 수준의 정밀도를 24개 검체까지 동시에.

개요 주요 특징 검사 메뉴 사양 자료

개요

검사실의 정확도, 동시 검사의 효율.

STANDARD F2400은 유로피움 기반 형광 면역분석 화학을 사용해 광범위한 정량 · 정성 분석을 제공하는 자동 분석기입니다. 자동 카세트 트레이로 다중 검체를 연속 처리해 병원과 검사센터의 처리량을 끌어올립니다.

3 ~ 15분검사 항목별 결과 도출 시간
최대 24동시 카세트 슬롯
10.1″컬러 TFT-LCD 터치스크린
5,000 건내장 결과 저장

주요 특징

자동화로 끌어올린 처리량과 신뢰성.

유로피움 형광 검출

큰 Stoke's Shift의 유로피움 화학을 UV LED 광원과 결합해, 일반 RDT 대비 향상된 민감도를 제공합니다.

연속 자동 처리

로딩 트레이에 카세트를 차례대로 투입하면, 분석기가 자동으로 순차 분석을 수행합니다.

2D 바코드 무코딩

카세트의 2D 바코드로 검사 종류 · 로트 · 유효기간을 자동 인식해 휴먼 에러를 줄입니다.

대용량 결과 저장

내부 메모리에 최대 5,000건의 결과를 저장하고, USB 또는 LAN으로 외부 백업이 가능합니다.

LIS / HIS 연동

HL7 표준 인터페이스로 병원 검사 정보시스템 · 진료 정보시스템과 즉시 연동됩니다.

10인치 와이드 UI

1024×600 컬러 터치스크린으로 다중 검체 진행 상태와 결과를 한눈에 확인합니다.

검사 메뉴

감염 · 심혈관 · 내분비 · 종양표지자.

STANDARD F 시리즈와 동일한 카세트를 공유하므로 폭넓은 검사 메뉴를 곧바로 활용할 수 있습니다.

  • 심혈관 — Troponin I / NT-proBNP / D-Dimer / CK-MB / Myoglobin
  • 내분비 — TSH / fT3 / fT4 / Cortisol / 25-OH Vitamin D
  • 염증 / 감염 — CRP / Procalcitonin / SAA / Ferritin
  • 종양표지자 — PSA / AFP / CEA / CA 19-9 / CA 125
  • 알러지 / 호흡기 — Total IgE / 호흡기 바이러스 패널

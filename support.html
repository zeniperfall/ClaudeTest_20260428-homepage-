정도관리

신뢰할 수 있는 결과를 위해.

정도관리(QC)는 검사 결과의 일관성과 정확성을 유지하기 위한 필수 절차입니다. 권장 QC 빈도와 절차, 기록 양식을 제공합니다.

  • 일일 점검 — 장비 자가진단(Self-Check), QC 카세트 / 솔루션 측정, 기록 관리.
  • 주간 / 월간 점검 — 정밀도 / 정확도 검증, 캘리브레이션 (해당 시), 기록 보관.
  • 로트 변경 시 점검 — 신규 로트 카세트 · 시약 도입 시 비교 검증.
  • 외부 정도관리(EQA) — 권역 학회 또는 공인 EQA 기관 프로그램 참여 권장.
  • 이상 결과 대응 — QC 실패 시 트러블슈팅 흐름과 기술지원 연락 절차.

FAQ

자주 묻는 질문.

STANDARD M10 카트리지는 재사용이 가능한가요?

아니요. STANDARD M10 카트리지는 1회용입니다. 핵산 추출 · 증폭 · 검출이 밀폐된 카트리지 내에서 진행되어 교차오염을 방지하며, 사용 후에는 의료폐기물 절차에 따라 처리해야 합니다.

STANDARD F 시리즈에서 F2400과 F200의 차이는 무엇인가요?

두 모델 모두 동일한 카세트 화학을 사용하지만, F2400은 자동 트레이로 최대 24개 카세트를 연속 처리하는 고처리량 모델이며 F200은 단일 카세트를 처리하는 컴팩트 데스크탑 모델입니다. 검사 메뉴는 거의 동일하게 호환됩니다.

STANDARD Q 카세트는 분석기 없이 사용 가능한가요?

네. 대부분의 STANDARD Q 카세트는 육안 판독으로 사용할 수 있습니다. 정량 결과나 데이터 관리를 원할 경우 STANDARD F 분석기와 결합해 사용하시면 됩니다.

병원 EMR / LIS와 자동 연동이 되나요?

네. STANDARD M10 · F2400 · F200은 HL7 표준 인터페이스를 지원해 LIS / HIS와 즉시 연동할 수 있습니다. 도입 시 IT 부서와 협의해 인터페이스 설정을 진행합니다.

정도관리 데이터를 외부에 보고해야 하나요?

국가 / 기관별 정도관리 정책을 따르며, 일반적으로 권역 학회나 공인 EQA 기관의 외부 정도관리 프로그램에 참여하는 것이 권장됩니다. 내부 QC 데이터는 분석기 또는 Data Manager에 자동 기록됩니다.

STANDARD G 측정기는 어디서 구입할 수 있나요?

전국 약국과 일부 온라인 채널에서 구매 가능합니다. 의료기관 / 도매 도입 문의는 본 페이지의 문의하기를 통해 접수해 주세요.

제품 결함이 의심될 때 어떻게 해야 하나요?

증상과 발생 시점, 로트 번호를 확인하신 뒤 아래 기술지원 연락처로 문의해 주세요. 안전성 이슈로 의심되는 경우 즉시 사용을 중단하고 보관해 주시기 바랍니다.
